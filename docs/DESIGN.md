# japan-rail-guide 設計書（ドラフト v0.2）

壁打ちで決めた内容のまとめ＋実現可能性メモ。作成日: 2026-10-07

**v0.2 の方針転換:** 時刻表・乗換・運行情報ではなく、**「見て楽しめる鉄道の基本情報データベース」**を軸にする。時刻表・乗換・運行情報はロードマップ後半に残す（v0.1の案は §7 に保存）。

## 1. ゴール
- 全国の鉄道（事業者・路線・駅・車両形式）を、暇つぶしに眺めて調べて楽しめるデータベースアプリ。
- 利用者はアカウント不要、URLを開くだけ。
- データは月1回程度、自動で更新される。

## 3. アーキテクチャ案（たたき台）
```
[GitHub Actions: 月次] 国土数値情報・OSM・Wikidata等を取得 → 検証 → 正規化・名寄せ
                       → 静的JSON／PMTiles生成 → ビルド → GitHub Pages
[フロント: React/Vite PWA] 静的ファイルを読み込み。検索・ランキングはブラウザ内
```
- 駅・路線に永続IDを振り、将来の時刻表／運行情報データを同じIDに紐付けられるようにする。
- 駅詳細・路線詳細は個別JSONに分割し、必要なものだけ読み込む（容量対策）。
- 共有URLは静的ホストなのでハッシュルーティング（`#/station/xxx`）を第一候補にする。

## 4. 画面構成（たたき台）
トップ（全国地図＋検索／ランダム／ランキング）／事業者ページ／路線ページ／駅ページ／車両形式ページ／ランキング一覧／都道府県・地方別一覧／お気に入り／出典・ライセンス表記。

## 5. 実現可能性メモ
確認できたこと（検索結果ベース。一次情報での再確認は未了）:
- 国土数値情報（国土交通省）に鉄道路線・駅のGISデータがあり、無償提供されている。年次の時系列データも含む。
- 公共交通オープンデータセンター（ODPT）は、鉄道・バス等のデータをREST API（JSON）で提供している（後半ロードマップ用）。

**確認できていない／要調査（推測で埋めない）:**
1. OSMの正確なライセンス・出典表記条件（国土数値情報は §5.1、Wikidataは §5.2 で確認済み）。OSMはODbL（共有義務の範囲を要確認）。
2. 各項目の取得可否：営業キロ・軌間・電化方式・複線/単線・駅の乗降客数（国土数値情報の駅別乗降客数の対象年度・欠損）・駅の構造・ホーム数・開業年・標高・読み仮名・路線カラー・駅ナンバリング。
3. 事業者名・路線名・駅名の名寄せ（データ源ごとに表記・IDが違う）。
4. 新幹線・ミニ新幹線をデータ上でどう識別できるか。
5. 全国PMTilesのサイズ・生成方法と、GitHub Pagesの容量目安（サイト1GB程度）に収まるか。
6. Wikidataの鉄道車両形式データの充実度。図鑑が成立するか。
7. Wikimedia Commonsの画像をアプリから表示する際のライセンス・帯域・埋め込み条件。
8. Wikipedia要約のCC BY-SA表示要件（帰属・継承の条件）がアプリ全体のライセンスに与える影響。

### 5.1 国土数値情報の調査結果（2026-10-07、公式ページと実データで確認）
一次情報: 各データのページ（`nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-{N02,S12,N05}-*.html`）、利用規約（`.../ksj/other/agreement_01.html`）、実際にダウンロードしたN02-24・S12-24のGeoJSON。

**ライセンス**
| データ | 条件 | 本アプリでの扱い |
|---|---|---|
| 鉄道（N02） | 2020年以降はオープンデータ（CC BY 4.0） | **使える**。出典＋加工した旨を表示 |
| 駅別乗降客数（S12） | CC BY 4.0 | **使える**。ただし事業者提供の統計で一部非公開 |
| 鉄道時系列（N05） | **非商用。複製物の再配布は不可**（原典の「停車場変遷大辞典」の許諾による） | **静的ファイルとして配布するこのアプリでは使わない** |
- 出典の書き方（規約より）: `出典：「国土数値情報（○○データ）」（国土交通省）（当該ページのURL）（○年○月○日取得）`、加工した場合は `「国土数値情報（○○データ）」（国土交通省）（URL）を加工して作成`。国が作成したように見せない。
- データに第三者の権利が含まれる場合がある（規約）。データごとの注記を取り込み時に確認する。

**鉄道データ（N02）** 最新は2025年度版（ページ上の選択は2024年度版。取得したのは2024年度版N02-24、zip 12.1MB）
- 形式: GeoJSON／Shapefile／GML。座標系 JGD2011。
- 規模（N02-24）: 路線区間 21,932本（LineString）、駅 10,235件。**駅も点ではなくLineString**（中心点の計算が必要）。事業者179社、(事業者, 路線名)の組み合わせ597。
- 路線の属性は 鉄道区分・事業者種別・路線名・運営会社 の4つだけ。駅は これに 駅名・駅コード・グループコード が付く。
- **営業キロ・軌間・電化方式・複線/単線・開業年・路線カラー・読み仮名は含まれない。**
- 事業者種別: 1=新幹線(245区間)、2=JR在来線、3=公営、4=民営、5=第三セクター。新幹線は9路線（北海道・東北・上越・北陸(JR東/JR西)・東海道・山陽・九州・西九州）で、**事業者種別で確実に識別できる**。
- 鉄道区分: 普通鉄道、鋼索、懸垂式、跨座式、案内軌条式、軌道(路面電車)、モノレール等を含む（1,460区間が軌道）。
- ミニ新幹線: 山形新幹線・秋田新幹線という路線は無く、**奥羽線・田沢湖線（JR在来線）として入っている**。「新幹線」タグは別途の補正テーブルで付ける必要がある。
- 路線名は混在: 「東北線」「中央線」「信越線」「奥羽線」のような法令上の線名（「本」が付かない形）と、「山手線」のような愛称レベルの線名が同居する。**事業者内で名前の粒度がそろっていない**ので、愛称・系統名の紐付け（既定方針）は必須。同名の別路線もある（例: 山手線は JR東日本と神戸市の2つ）。
- 駅の名寄せ: 駅コード（緯度の降順で振った番号）は年度で変わる可能性がある。グループコード（300m以内の同名駅）は乗換駅の同一視に使えるが、近接しない乗換駅は別扱い。**永続IDは自前で振る**必要がある。

**駅別乗降客数（S12）** 最新データは2024年度版（ページ上の更新は2026年4月）。データ有無コードの扱い
- 10,531件。属性は 駅名・駅コード・グループコード・運営会社・路線名・鉄道区分・事業者種別 ＋ 年度ごと（2011年度〜）の 重複コード／データ有無コード／備考／乗降客数。
- 最新年度で乗降客数が1以上の駅: **8,097/10,531（約77%）**。残りは非公開・データなし・廃止等。
- データ有無コード（最新年度）: 1=あり 8,919／2=1,355／4(駅なし)=255／0=2。備考に「新駅」「廃止」「東海道線を含む」など。
- **複数路線の駅は「中心に近い駅」にだけ乗降客数が付く**（重複コード）。そのため、駅単位のランキングには駅の名寄せと合算ルールが必須。例: 新宿の最大値は中央線の行（1,301,204人/日）に載り、京王線の行にも別の値（1,050,497）が載る。
- ページの注記: 年度は「データの整備年度」で、元資料は1年遡る。

**§5 要調査項目への影響**
- ランキング（駅の乗降客数）・新幹線タグ・路線一覧は、N02＋S12で成立する。
- **営業キロ・軌間・電化方式・複線/単線・開業年・駅構造・ホーム数・路線カラー・駅ナンバリング・読み仮名・標高は、国土数値情報だけでは取れない。**N05（開業年あり）は非商用・再配布不可で使えないため、開業年はWikidata／OSM／事業者公開情報で補う必要がある。この点は設計の前提に影響する（§6）。
- 路線の長さは、N02の線形状から距離を計算した値（営業キロとは別物）として出せる。表示するなら「地図上の延長」と明記する。

### 5.2 Wikidata の調査結果（2026-10-07、SPARQLで実測）

| 駅 | 9,599 | 9,449 (98%) | ― | ― | ― | ― | 8,729 (91%) | 9,598 | 9,501 |

- 路線のうち廃止（P576あり）が64件、駅のうち廃止・用途廃止等が約1,410件。現存路線だけに絞ると路線の分母は約650、駅は約8,200。
- 駅: 座標 9,397、ホーム数/ホーム面数 6,427 (67%)、駅コード(P296) 7,654件。
- **軌間の内訳:** 1067mm 480／標準軌 84／762mm 18／スコッチ(1372mm) 13。ほぼ実態どおり。
- **電化方式の内訳:** 直流1500V 310／非電化 144／直流600V 27／交流20kV 50Hz 23・60Hz 18／直流750V 14 ほか。
- **車両形式:** 日本原産の鉄道車両形式が **602件**（日本語ラベル584、日本語Wikipedia 579）。うち画像あり 171、**運用開始日 65、製造会社 109、運行事業者 361**のみ。事業者が日本の会社の形式だと2,171件（編成単位などが混ざる可能性あり）。→ **「形式の一覧とWikipedia解説」は成立するが、スペック（運用開始年・製造会社・最高速度等）は薄い。**
- **駅コード(P296)は品質が不揃い。** 札幌駅は「01」と電報略号「サツ」、東京駅は「トウ」（電報略号）が入り、「JY01」のような駅ナンバリングは入っていない例が多い。**ナンバリングは Wikidata だけでは足りない。**
- N02との突き合わせ（名前ベースの簡易照合）:
  - **駅名: N02の8,504駅名のうち 7,444 (88%) が Wikidata に同名あり**（うち同名で複数該当 313）。
  - **路線: N02の597路線のうち 422 (71%)** が名前＋事業者で照合できた。JRは179路線中38が未照合（理由: N02は「鹿児島線」「函館線」「宗谷線」のように法令上の線名・「本」なし表記で、Wikidataは「鹿児島本線」など通称）。私鉄・第三セクターでは事業者名の表記ゆれ（「アイジーアールいわて銀河鉄道」等）が原因。
  - N02のデータに**事業者名と路線名が入れ替わっている行**がある（例:「三国芦原線」×「えちぜん鉄道」）。取り込み時に検証して補正表に載せる。
- ライセンス: Wikidataの構造化データはCC0（一般的な知識。公式ページでの再確認は未了）。

**判断への影響**
- 開業年・軌間・電化・長さ・路線の事業者・駅の開業年は、Wikidataで**7〜9割台**まで補える。国土数値情報に無い項目の大半を埋められる見込み。
- 駅構造（ホーム数）は約7割。標高(P2044)・駅ナンバリングは別ソース（国土地理院、OSM、補正表）が必要。
- 結び付けは「名前＋事業者＋座標」で行い、取れない分は補正表（`data/overrides/`）で手当てする。完全自動は無理で、**JRの法令名↔通称の対応表は最初に作る必要がある**。
- 路線の「長さ(P2043)」が営業キロなのか、別の長さなのかは未確認。値を比較してから使う。

### 5.3 OSM の調査結果（2026-10-07、OSM Wikiで確認。実データでの網羅率は未測定）
一次情報: OSM Wiki の `OpenRailwayMap/Tagging_in_Japan`、`JA:Tag:route=train`、`JA:Tag:railway=station`。
- **路線カラー:** `colour=*` は運行経路（`route=train`）に付ける**任意**タグで、Wikiの説明は「一部の都市の地下鉄路線のように、運行経路に公式の色がある場合に使う」。→ 全国をカバーする前提にはできない。
- **駅ナンバリング:** 駅のタグ付け規約に、JY01のような駅ナンバリング専用のタグは見当たらない（`uic_ref` はUIC登録コード、`railway:ref` は事業者の分岐点等の参照記号の用途）。→ **OSMから取る前提にはできない。**
- 軌間(`gauge`)・電化(`electrified`＋電圧)・事業者(`operator`、会社の正式名称)は規約が明確だが、これらは Wikidata で既に7〜9割台が取れるため、OSMは補助。
- ライセンスはODbL（一般的な知識。共有義務の範囲は要確認）。出典は「© OpenStreetMap contributors」。
- 実データでの網羅率: この環境から Overpass API に接続できず、Geofabrik 等も許可リストに無いため**未測定**。
- **決定（2026-10-07）:** 路線カラー・駅ナンバリングは最初から**補正表（`data/overrides/`）を主**として作る。OSMの実測は後回し。

## 7. ロードマップ案
1. **フェーズ1:** 雛形・CI・データ取得パイプライン。全国地図に路線・駅を表示、路線／駅ページ。
2. **フェーズ2:** 検索・絞り込み、都道府県別一覧、ランキング・トリビア。
3. **フェーズ3:** 事業者ページ、車両形式の図鑑、写真・解説文（Wikimedia／Wikipedia）。
4. **フェーズ4:** お気に入り、共有URL、PWAのオフライン対応。
5. **後半:** 時刻表 → 乗換案内 → 運行情報（v0.1の方針。オープンデータの規約・提供範囲は要調査。運行情報は取得できる事業者のみ・最終更新時刻を表示する案）。

## 7.1 フェーズ1の実装状況（2026-10-07）
- データ: 国土数値情報 N02-25（2025年度版）・S12-25（2024年度版の乗降客数）から生成。路線596・駅9,046（同名300m以内をまとめた単位）・事業者176。乗降客数のある駅 7,393（82%）。
- 画面: トップ（全国地図、路線・駅をタップで選択カード）／路線ページ（駅の並び・乗換路線・小地図）／駅ページ（駅名標風、乗り入れ路線、乗降客数と内訳・推移）／路線一覧（種別・事業者別、絞り込み）／出典・説明。
- 共有URL: `#/line/<ID>`・`#/station/<ID>`。IDは事業者名＋路線名、駅名＋座標（約1km格子）から作る安定ハッシュ。
- 自動更新: GitHub Actions で月1回。検証に失敗したら前回データを維持。
- 補正表（2026-10-07）:
  - `scripts/sync-wikidata.ts` で国土数値情報の路線と Wikidata 項目を照合し、`wikidata_lines.csv` に保存（人が差分を確認してコミット）。596路線中 565 を照合（項目名一致309・別名一致218・末尾一致38）、路線色は 409 路線。表示名・路線色はこれを使う（手書きの `line_aliases.csv` / `line_colors.csv` が優先）。
  - 未照合の31路線（路面電車・ケーブルカー・横浜市営地下鉄の「1号線」など、東武伊勢崎線のように候補が2つに割れたもの）は元データの名前と既定色のまま。必要に応じて手書きの補正表で埋める。
  - ミニ新幹線は `virtual_lines.csv` の「通称区間」として追加（山形新幹線＝奥羽線 福島〜新庄、秋田新幹線＝田沢湖線 盛岡〜大曲＋奥羽線 大曲〜秋田）。区間は Wikidata の終点と日本語版Wikipediaで確認。
  - Wikidata の路線色は、Wikipedia 等で使われる色で、事業者の色指定と細部が異なる場合がある（画面に注記）。
- 既知の課題（フェーズ2以降）:
  - 路線の範囲は法令上の線名ごとのまま（例: 山手線は品川〜新宿〜田端の17駅）。環状運転の「山手線」としての見せ方は未対応。
  - 駅ページの乗降客数の内訳は元データの路線名（例:「京浜急行電鉄 本線」）のまま。
  - 地図上の駅名ラベルは未表示（日本語フォントのグリフ配信が必要）。駅名はホバー／タップで表示。
  - 駅の並び順は線形からの自動推定で、支線のある路線では前後することがある。

## 7.2 フェーズ2の実装状況（2026-10-07）
- 検索（`#/search?q=`）: 駅名・路線名・事業者名。ひらがな・カタカナ・ローマ字（Wikidataの読み仮名・英語名）に対応し、全角半角・長音記号・ヘボン式の揺れを吸収。
- 条件絞り込み（路線一覧）: 都道府県・種別・開業年代・軌間・電化方式。開業・軌間・電化は Wikidata に登録のある路線のみ。
- 都道府県（`#/prefs`・`#/pref/<名前>`）: 地方別の一覧、県ごとの路線・乗降客数上位の駅・市区町村別の駅。
- ランキング・トリビア（`#/rankings`）: 乗降客数、乗り入れ路線数、路線の延長・駅数、開業の古い路線・駅、新しい駅、東西南北の端の駅、名前の長い駅、1文字の駅、事業者別の延長・駅数。
- トップ: 検索窓、ランダム（駅）、ズーム9以上で「この範囲の駅・路線を一覧」。
- データ追加:
  - 駅の所在地: 国土数値情報「行政区域（N03、2025年1月1日時点）」を約40m精度に簡略化した `data/static/admin_areas.json`（`npm run data:boundaries` で作り直す。毎月の更新では使い回す）で判定。全9,046駅に都道府県・市区町村が付く（境界の外に出た9駅は500m以内の最寄りの市区町村）。
  - Wikidata（`npm run data:wikidata`）: 路線の開業日540・軌間527・電化方式509、駅の照合8,453（読み仮名6,962・ローマ字8,452・開業日8,442）。駅は名前一致かつ1.5km以内の最も近い項目と照合。
- 見送り: 駅の標高（Wikidataの登録が約6%しかない。国土地理院の標高データを使う方法を後で検討）。
- 既知の注意点: Wikidataの開業日には前身の鉄道の開業日が入っている路線がある（例: 根岸線が1872年）。ランキングに注記した。
